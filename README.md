# Instagram

A personal Instagram companion project. The repository keeps the name `Intagram-nerfed`; the requested home-screen name is **Instagram**, with the 2016 gradient camera icon.

## Project status

Requirements and platform feasibility are documented. The Instagram integration and application are **not implemented or deployed yet**.

The revised requested experience is personal Instagram messaging without Feed, Explore, or Reels, with occasional story posting. The user confirmed a **Personal** account and an iPhone home-screen website. Blocking, daily passes, and timed unlocks are no longer requested.

The remaining integration constraint is the personal inbox: Meta's supported messaging API serves professional accounts, and a standalone website cannot modify Instagram's pages or read its signed-in inbox across origins. Removing app blocking does not remove that constraint. A link to Instagram is not a custom inbox implementation.

- [Verified platform constraints and implementation options](docs/platform-feasibility.md)
