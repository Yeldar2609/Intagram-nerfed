# Intagram nerfed

A free, distraction-reduced Instagram companion project.

## Project status

Requirements and platform feasibility are documented. The Instagram integration and application are **not implemented or deployed yet**.

The requested experience is personal Instagram messaging without Feed, Explore, or Reels, plus an optional lock with two short daily access passes. The requested installation is an iPhone home-screen website.

That full combination cannot be delivered by a standalone website: it cannot modify Instagram's pages, read the signed-in personal inbox across origins, or invoke Apple's native Screen Time controls. A different installation method is needed for those features. A link to Instagram and a local countdown would not satisfy them.

- [Feature requirements and acceptance checks](docs/requirements.md)
- [Verified platform constraints and implementation options](docs/platform-feasibility.md)
