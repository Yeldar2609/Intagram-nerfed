Instagram, less scrolling.

Friends, stories and messages. Free. No imports.

Install on iPhone

Open this page in Safari.

  1. Get Userscripts (free).

    Open it once. In Settings → Apps → Safari → Extensions, turn on Userscripts.

  2. Install the script.

    Tap below, then Safari’s page menu → Userscripts → Install. Allow access if asked.

    Install / update script
  3. Open Instagram.

    Allow Userscripts on instagram.com, refresh, and sign in. Use Instagram’s original buttons.

Add to Home Screen
  1. Save the classic icon to Photos or Files.
  2. In Apple Shortcuts, add URL: https://www.instagram.com/, then Open URLs.
  3. Name it Instagram. Choose Add to Home Screen, tap the icon, and select your saved image.

Set Safari as your default browser. This shortcut opens Safari so the extension can run; use this instead of Safari’s standalone web-app shortcut.

Updating or need help?

Replace your old script using the install button above. Keep only one copy enabled, close Instagram tabs, and reopen. Install v0.3.1; there is no Focus button.

Still seeing the old custom buttons? Replace the old script, close Instagram tabs, and reopen. If installation does not appear, save the script into the folder shown in the Userscripts app.

Already have a home-screen shortcut? Set its URL to https://www.instagram.com/.

Friend checks are automatic. No imports. Search uses Instagram’s own people results, with Explore posts hidden. If posts cannot be verified, a short message explains why; stories and messages remain available.

Install on a computer
  1. Download the extension and unzip it.
  2. Open chrome://extensions or edge://extensions. Enable Developer mode.
  3. Choose Load unpacked and select the folder with manifest.json.

Safari on Mac: use the Userscripts steps above.
