01 / SAFARI

Connect it to your real Instagram.

You sign in on instagram.com. This project never asks for your password and has no messaging server.

  1. Install Userscripts, the open-source Safari extension. Open it once to initialize its script folder.
  2. In iPhone Settings, open Apps → Safari → Extensions → Userscripts and enable it. On older iOS versions, Safari is directly in Settings.
  3. Open the script below in Safari. Open Safari’s page menu, select Userscripts, and choose its installation prompt. Allow access to this installation page if prompted.
  4. Open Instagram Messages. Allow Userscripts on instagram.com, then refresh. Sign in on Instagram if needed.
Open the iPhone script

Alternative: save the .user.js file into the folder shown in the Userscripts app, then open its Safari menu and refresh Instagram. You only need this script installed once.

Check before relying on it

You should see a small Focus button on Instagram. If it is missing, the extension is not running. Try refreshing, checking site permissions, and opening the Userscripts menu.

02 / YOUR HOME SCREEN

The classic icon. The name you know.

Save the original icon

Use an Apple Shortcuts home-screen icon that opens the inbox in Safari. A standalone “Add to Home Screen” web app may not run Safari extensions, so it is not the supported setup here.

  1. Save the icon above to Photos or Files.
  2. In Shortcuts, create a shortcut with a URL action containing https://www.instagram.com/direct/inbox/, followed by Open URLs. Use Safari as your default browser.
  3. Name the shortcut Instagram. Open its details/menu and choose Add to Home Screen.
  4. Tap the icon → Choose Photo or Choose File, select the downloaded classic icon, then tap Add.

The icon launches Safari, where the extension runs. Check for the Focus button after launching. Shortcuts and menu labels can vary by iOS version.

03 / WHEN YOU WANT TO POST

Messages first. Posting when you need it.

On Instagram, tap Focus → Open posting mode. Instagram’s regular navigation returns. Use its own Create control, then choose Posting mode → Back to messages when you finish.

Story uploading is available only if Instagram offers it for your account and browser. This extension does not add unsupported story uploads. There are no timers, daily passes, or app locks.

Posting mode stays active in that tab until you return to Messages. Authentication, message delivery, notifications, attachments, and calls are provided by Instagram and depend on its web support. Reel links are hidden in focus mode, including shared Reel links; switch to posting mode to open them.

04 / CHROME & EDGE

A small extension. No subscription.

  1. Download and unzip the extension.
  2. Open chrome://extensions or edge://extensions and turn on Developer mode.
  3. Choose Load unpacked and select the extracted folder containing manifest.json.
  4. Open Instagram Messages and check for the Focus button.
Download desktop extension

For Safari on Mac, use the same Userscripts installation as above. Remove the script or disable the extension to restore the original Instagram website.

No analytics, no subscriptions, no password collection. The extension only changes Instagram’s interface. This installation page is hosted on GitHub Pages; GitHub and Instagram apply their own privacy policies.
